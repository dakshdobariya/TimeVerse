# 🌍 World Clock Website

A modern and responsive multi-page World Clock website built using HTML, CSS, and JavaScript. This project allows users to view live time from different cities around the world through a clean and professional interface.

## 🌐 Live Demo

🔗 https://dakshdobariya.github.io/world-clock-website/

## ✨ Features

* Live world clocks
* Multiple city time zones
* Responsive design
* Modern UI
* Smooth hover effects
* Multi-page navigation
* Beginner-friendly code structure

## 📂 Pages

* Home
* Clocks
* About
* Contact

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
