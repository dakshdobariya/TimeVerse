About Global Time Hub

Global Time Hub is a modern world clock application designed to help users track real-time time zones from major cities around the globe. Built with HTML, CSS and JavaScript, it provides live clock updates, dark mode support and a clean user experience.

🚀 Our Mission

To provide accurate live world time information in a clean and modern interface.

🌎 Global Reach

Track multiple cities and time zones from around the world in real time.

⚡ Fast & Modern

Built using HTML, CSS and JavaScript with a premium user experience.
